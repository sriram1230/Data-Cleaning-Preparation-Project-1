# Project 1 – Data Cleaning & Preparation

## Objective
Clean and validate a raw dataset by identifying missing values,
duplicates, incorrect formats, and data inconsistencies.

## Tasks Performed
- Checked for duplicate OrderIDs
- Checked missing values
- Verified date formatting
- Validated Quantity values
- Validated UnitPrice values
- Verified TotalPrice calculations

## Results
- Total records: 1,200
- Duplicate OrderIDs: 0
- Missing Date values: 0
- Date format: YYYY-MM-DD
- Blank CouponCode values: 309
- Quantity validation: Passed
- UnitPrice validation: Passed
- TotalPrice validation: Passed
